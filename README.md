# Organizacion del repo

El repo esta separado en 3 carpetas principales:

- content: contiene assets del juego y niveles.
- gyms: niveles y sistemas de prueba
- systems: sistemas principales del juego (el jugador, interactuables, etc)

Esta roganizacion se basa en el siguiente articulo: https://www.gdquest.com/library/modular_game_architecture/
